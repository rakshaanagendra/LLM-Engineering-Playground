\# Overview



This repository contains practical experiments and learning projects focused on:



\- Transformer architectures

\- Tokenization and embeddings

\- Text generation workflows

\- NLP pipelines

\- LoRA/QLoRA fine-tuning

\- Hugging Face ecosystem

\- Foundational RAG components



The goal of this repository is to build a deeper understanding of modern LLM engineering concepts through hands-on implementation and experimentation.

\# Setup



\## Clone Repository



```bash

git clone https://github.com/rakshaanagendra/LLM-Engineering-Playground.git

cd LLM-Engineering-Playground

```



\## Create Virtual Environment



```bash

python -m venv rag

```



\## Activate Virtual Environment



\### Windows

```bash

.\\rag\\Scripts\\activate

```



\### Linux / Mac

```bash

source rag/bin/activate

```



\## Install Dependencies



```bash

pip install -r requirements.txt

```
